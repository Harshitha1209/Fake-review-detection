Base Paper Summary

Title
Revealing the Reliability of Amazon Products via Innovative Fake Review Detection using Machine Learning
Key Methodologies
  • BERT (Bidirectional Encoder Representations from Transformers): Used for deep contextual understanding of review text.
  • LSTM (Long Short-Term Memory): Used to capture sequential patterns in text.
  • Hybrid Approach: Combining textual analysis with metadata features (Verified Purchase, Review Length).
Results
  • Accuracy: The proposed BERT model achieved an accuracy of 96.3%.
  • Comparison: Outperformed traditional models like SVM (80.6%) and Random Forest (81.1%).
  • Dataset: Trained on a balanced dataset of 50,000 reviews (35k Authentic, 15k Fake).
